# 🍎 사과게임

사과 숫자를 손가락으로 쭉 그어 **합이 10**이 되게 모으면 사과가 팡 터지는 120초 퍼즐 게임입니다.
폰 · 태블릿 어디서든 한 화면에 꽉 차게 놀 수 있습니다.

**바로 플레이 → https://chohanui2-home.github.io/apple-game/**

## 노는 방법

1. 사과판 위에서 손가락(또는 마우스)으로 **사각형을 쓱 드래그**합니다.
2. 골라진 사과 숫자의 **합이 정확히 10**이면 사과가 팡! 터지고, 터진 사과 개수만큼 점수가 오릅니다.
3. 합이 10이 아니면 사과는 그대로 남고 선택만 풀립니다. (미리 합을 알려 주지 않으니 암산으로!)
4. **120초**가 끝나면 최종 점수와 터뜨린 사과 개수를 보여 줍니다.

- `🍎 시작하기`를 누르는 순간부터 120초가 줄어듭니다. 들어오자마자 시간이 흐르지 않습니다.
- `🔄 다시` / `🔄 다시 하기`는 새 판을 깔고 다시 대기 상태로 돌아갑니다.
- `🔊 소리`로 효과음을 끄고 켤 수 있습니다.

## 화면 크기별 판

| 화면 | 판 | 시간 게이지 |
|---|---|---|
| 세로 폰 (390×844 등) | **10열 × 14행 (140개)** | 위쪽 가로 초록 게이지 |
| 태블릿·가로 (640px 이상) | **17열 × 10행 (170개)** | 오른쪽 세로 초록 게이지 |

두 경우 모두 가로 스크롤 없이 한 화면에 들어가며, 판은 남는 공간에 맞춰 자동으로 커지고 작아집니다.

## 만든 방식

- `index.html` **한 파일**입니다. 외부 CDN·폰트·이미지·스크립트 요청이 **0건**이라 비행기 모드에서도 열립니다.
- 사과 그림은 문서 안에 심은 SVG 한 개를 재사용하고, 숫자는 그 위에 흰 글씨로 얹었습니다.
- 점수·기록을 **어디에도 저장하지 않습니다**(`localStorage` 사용 0건). 교실 공용 태블릿에 흔적이 남지 않습니다.
- `viewport-fit=cover` + `env(safe-area-inset-*)`로 노치·홈바를 피합니다.
- 숫자는 10이 되는 짝(예: 3+7)을 중심으로 배치하고 섞어서, 어느 판이든 합 10 조합이 넉넉히 나옵니다.

## 파일

- `index.html` — 게임 본체 (배포되는 파일)
- `app_template.html` · `build.py` — 아이콘을 심고 단일 파일 규칙을 검사해 `index.html`을 만듭니다
- `test_app.py` — 정적 규칙 + QuickJS로 실제 스크립트를 돌리는 규칙 테스트
